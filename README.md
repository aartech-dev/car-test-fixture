# Slot Car Test Block

This is a "vibe coded", AI-developed slot car test block. I wanted something on which I could place a car and power 
it while doing some testing. It might need some refinements, I was thinking of a little neo magnet to locate the chassis - please tell me what ...

## v7 (`setup_block_metric_v7.py`)

- Lid resized to 194 x 104 mm (box scales to match).
- Tire clearance cutouts changed from a rear-only pair to four symmetric cutouts
  (front + rear, left + right) so all four tires clear: 50 x 28 mm each, 22 mm from
  the nearest short edge, 10 mm from the nearest long edge.
- Guide slot pulled in 7 mm from the front edge and shortened to a closed
  (rounded-both-ends) 50 mm pocket instead of opening to the edge; the braid
  channels and their feed-through cross-slots were adjusted to match.
- Added the neo magnet recess: 5 mm diameter, 2 mm deep, dead centre in the top face.
- Box wall thickness increased to 4 mm, with the lid's tongue inset matched to it
  (4 mm), so the rim lip that locates the lid in the box is a solid ~3.8 mm ledge
  instead of the previous 0.8 mm sliver.
